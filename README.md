# Equation Bubble — Clear View v12.0

瀏覽器開啟 index.html；雙人入口為 battle.html。保留浮島像素美術、五位老師、精確分數、碰牆反彈及解題驗算。

## 模式與操作

- 輔助模式：選運算，依瞄準目標自動配數值。
- 挑戰模式：自行輸入非零整數或分數（例如 3、-3、1/2）；數值欄輸入期間不觸發遊戲快捷鍵。選 ×LCM 後亦需自行計算乘數。
- 練習模式（單人）：停止下降，可配合以上任一模式。
- 單人：左右瞄準、上下換運算、Space/Enter 發射、H 分級提示、P 暫停。
- 雙人：P1 A/D、W/S、F、G；P2 方向鍵、Enter、L；P 同時暫停。
- 提示逐級顯示目標、運算種類、完整數值及自動瞄準；最後一級可在挑戰模式提供協助。狀態變更後從第一級開始，只提示未被下方題目擋住的直射目標。

## 數學與關卡

五關：一步、兩步、兩邊未知數、括號、分數與 LCM。每關解四題；升關清場，避免混入前一關題目。
本遊戲採用指定教學路線：消去左方常數及右方 x 項後才除係數；括號 k(x+b)=c 先除 k。這是本關要求，不代表其他等價方法在數學上錯誤。
所有操作同步施於等式兩邊，BigInt 有理數保持精確，變換檢查解不變，完成後代入原式驗算。題庫答案目前為整數；分數關重點是分數係數與最小公倍數。
四題開場、兩列錯落、慢速持續下降、逐題補題。每發只操作一條；沒有跨題連鎖或射擊次數壓頂。單人碰線扣一心、其他題目震退，提供 1.8 秒保護，避免同時連扣。

## 雙人公平性

雙方共用種子普通題庫及相同開局。整條特殊方程上方標有「★ 解完整題 → 攻擊」；解出並驗算後才追加一題。攻擊延遲約 0.9 秒，有空間才入場；攻擊題不帶星。
攻擊題採用獨立種子串流，不消耗普通題庫次序，亦不改變普通題星號頻率。收到攻擊造成的場面壓力仍屬對戰效果。三心全失落敗，同影格同時失去最後一心為平手。

執行 node tests.cjs、node arcade-tests.cjs、node versus-tests.cjs、node battle-ui-tests.cjs 及 node classroom-tests.cjs。
流程測試採 DOM fixture，不等同實體 iPad 或多人鍵盤測試。美術使用原有 assets，離線使用需保留整個資料夾。
