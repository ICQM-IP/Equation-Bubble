# Equation Bubble — Math Down Adventure v5.0

直接用瀏覽器開啟 index.html。無需安裝或連線；所有素材均在 assets/。GitHub Pages 部署時上傳整個資料夾。

## 新外觀

以提供的預覽圖為參考，使用獨立像素場景、透明 Yeung Sir、青綠黃銅炮台、泡泡素材重做。分數、生命、關卡、方程式、炮彈和教學木牌文字全部是即時遊戲內容。1672×941 設計舞台按螢幕等比縮放；iPad 建議橫向。

預設從第二關開始，開場使用預覽中的 3x−2=4 和 5x+5=35。開始畫面可選第一至第五關及不下降的練習模式。

## 操作

- 左右方向鍵：按住調整炮管角度。
- 上下方向鍵：輪換完整炮彈，如 −5、÷3；同類運算可能有不同數值。
- Space / Enter：發射，依實際路徑碰撞第一個項，可碰牆反彈。
- 點擊底部彩色運算泡泡：切換該類炮彈。
- H：裝填正確步驟、標示目標並協助瞄準。
- P：暫停／繼續，包括射擊與教學動畫。
- 觸控：點遊戲區瞄準，或用出現的左右／換彈／發射按鈕。
- 重開：重新開始；結束畫面可回到選關。

命中有效項後，右側木牌先顯示兩邊同一操作，再化簡。解成 x=答案後自動代入原式並消除。每關清四題，共五關。連續消除累積 combo；失誤重置 combo；碰線扣心。

## 數學

BigInt 最簡有理數；所有加減乘除同步施於等式兩邊；拒絕乘零、除零及不合消元步驟的操作。有常數項時不可提早除以 x 的係數。括號以 ×1 表示等值的分配律展開。LCM 由所有分母精確計算。題庫保證唯一解，每次變換檢查解不變，消除前代入原式驗證。

## 驗證

`node tests.cjs`：2,500 條生成方程、負數、分數、非法操作、消元先後次序及代入。

`node arcade-tests.cjs`：在確定性 DOM fixture 中檢查啟動、黃色換彈標示、彈道命中、同步運算階段、暫停、化簡、自動消除、非法除法、重設安全及縮放座標。這是程式流程測試，不等同瀏覽器畫面或真實 iPad 測試。

## 檔案

index.html（入口）、arcade.html（同版獨立入口）、arcade.css、arcade.js、math.js、assets/。舊版 game.js、style.css 和 adventure.svg 留作參考，不由新版入口載入。

## v5.0 CHAIN REACTION

本版以「射擊次數壓頂」取代 v4.1 的持續下降。平時可思考；每射四發（包括失誤）整組向下壓 42 像素，最後一發前有警示。壓頂等待炮彈及整段連鎖動畫結束再結算。解題成功增加一發緩衝；若在壓頂前成功解題，可取消當次壓頂並取得一發空間。練習模式不壓頂。

反彈後命中合法步驟，額外 +75 分及一格能量。普通正確命中增加一格能量，最多三格；開場已充滿以示範連鎖。滿能量時，若另一條等式同樣適用該運算、數值及類型，顯示金色連線；命中後自動消耗三格，依次在兩條等式各自施行完整等價運算。每次最多連鎖一條額外等式，不遞迴連鎖；次要操作不產生額外充能。展開括號不直接連鎖，展開後的合法消元可連鎖。不合規的除法、不同 operand 或 x 項／常數項不會混用。

開場第二關為 3x−2=4 與 2x−2=8，可用 +2 示範雙重平衡。每波清空後補兩條具有共同結構但答案不同的方程，提供連鎖機會；上方有空間時仍可補題，最多三條。每關清四題。保留原版自動代入驗算與精確有理數規則。

流程測試新增：四發壓頂、思考不下降、末發解題救場、兩條等式連鎖、錯誤連鎖拒絕、真實反彈路徑加分、充能、碰線扣心及暫停。尚未完成真實瀏覽器與 iPad 互動測試。

## v6.5 SMART AMMO

## v6.8 DIVIDE BRACKETS

### 對打控制

- 玩家一：A/D 調角度、W/S 換運算、F 發射、G 提示。
- 玩家二：左右鍵調角度、上下鍵換運算、Enter 發射、L 提示。

### 特殊泡泡與攻擊

金色星號 ★ 標記特殊等式。必須把整條等式解成 x=答案，並通過原式代入驗算，才向對手追加一條等式；不是碰到星號就直接攻擊，也不會一次消除兩條題目。一般題目、無效操作或失誤不會送出攻擊。每次特殊題只增加一條，接收方先看到來襲預告，約0.9秒後入場。新增的攻擊題沒有星號，避免無限互相反彈。上方太擠時排隊等待安全空間，不覆蓋原題或立刻扣心。

雙方同題型、同一種子題庫及相同開局，計分與生命各自獨立。各三顆心；碰線扣一心，震退並有1.8秒緩衝。先失去三心者落敗，同影格同時失去最後一心為平手。可再戰或重新選角，新局清空所有飛彈與攻擊佇列。

數學沿用同一精確引擎：操作施於等式兩邊、先消常數再除係數、括號先除外係數、負數除數括號、上下分數、LCM只顯示實際乘數。每發只處理命中的那條等式。
